# Handover note

Copy this into the pull request and into every report. A check that was not run is **NOT ASSESSED**. Never call it passed.

## PASSED

- What was checked, and how.

## FAILED

- What failed. Name the screen, the text, or the check. If nothing failed, write "none".

## NOT ASSESSED

- What was not checked, and why. If a contrast sample could not be read, it belongs here, not in PASSED.

## GUESSED

- Assumptions this note relies on. If none, write "none".
